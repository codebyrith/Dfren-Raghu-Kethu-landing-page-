A modern, high-converting Vedic Astrology & Gemstone consultation landing page for **Raghu Kethu Peyarchi 2026–2027**.

- **Single High-Conversion Booking Package**: Centered ₹999 Gemstone Recommendation package.

- **Mobile Responsive**: Smooth drawer menu and sticky quick-booking bar.

## 🚀 Live Deployment on Vercel
This repository is configured for **Zero-Config Deployment on Vercel**:
1. Push this repository to your GitHub account.
2. Go to [Vercel](https://vercel.com/) and click **"Add New... Project"**.
3. Import your GitHub repository.
4. Click **"Deploy"** (no custom build settings required).

## 💻 Running Locally
```bash
# Clone the repository
git clone <your-repo-url>
cd rahu-ketu-astrology

# Start local dev server
npm start
# or
node server.js
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
